# Planned Views

## System Overview

Repository health, configuration resolution, Odoo version, active release, available environments, and blocking conditions.

## Requirement Intake

Incoming requirement documents, sidecar status, review findings, dependency readiness, and missing artifacts.

## Run Plan

Phases, tasks, dependencies, requested and actual models, validation gates, approval points, and completion evidence.

## Approval Inbox

Items awaiting review, source documents, changes, risks, evidence, and approve or reject actions.

## Active Run

Current task, execution adapter, assigned model, owner, worktree, branch, elapsed time, checkpoint, logs, and permitted controls.

## Release Readiness

Included requirements, exact product revision, tests, database rehearsal, open exceptions, approvals, and release disposition.
